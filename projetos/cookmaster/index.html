CookMaster / UebaChat

🧠 IA Generativa 🛒 Conversational Commerce 📄 Ingestão de Cardápios (PDF)

O CookMaster (originalmente desenvolvido como UebaChat / Ueba Doces) foi concebido como uma plataforma de Conversational Commerce e automação operacional para estabelecimentos gastronômicos, confeitarias e cozinhas comerciais.

✦ Evolução Tecnológica: O projeto transcendeu o conceito de cardápio digital para estabelecer um ecossistema inteligente de alta conversão. Tendo atingido sua versão 2.0 estável, serve de fundação arquitetural para as atuais tecnologias de inteligência de catálogo e atendimento da THP.

Diferenciais da Arquitetura v2.0

⚡

Cérebro IA Cloud-Native

Inteligência generativa baseada em nuvem com latência ultra-baixa. Executa grounding dinâmico no cardápio vivo a cada interação e valida regras estritas de pedido mínimo e disponibilidade.

📑

Smart Admin & Motor de Diff

Ingestão direta de cardápios em PDF com identificação comparativa automática de novos itens, alterações de valores e exclusões, com rotinas de backup instantâneo.

📱

Interface Gourmet (Mobile-First)

Frontend ultra-leve em Vanilla JS com carrinho estilo Bottom Sheet e Floating Action Button (FAB) com atualização em tempo real para maximizar a conversão no mobile.

Pilares Tecnológicos

Backend API
Python (Flask / FastAPI)

Estrutura modular em camadas e validação de schema com jsonschema.

Inteligência
Modelos LLM Cloud-Native

APIs de alta performance com grounding contextual dinâmico.

Frontend
Vanilla JS Gourmet

Design System ergonômico sem dependência de frameworks pesados.

Qualidade
Stress QA & Automação

Testes de injeção, controle de cota e pipeline com Makefile.
